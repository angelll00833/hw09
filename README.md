## 個人回答

### 問題一
測試一的桌遊整理串列有 `['amy', 'ben', 'amy', 'cora']` 共 4 筆，但 `'amy'` 在同一場重複報名，依規則同一場只算 1 位參加者、收費 1 次，所以桌遊人數是 3 人（`3 × 120 = 360.00` 元）。
直接把字串拆成 `list` 可以保留原始出現順序與重複報名紀錄，但沒有去重，不能直接用長度算人數或收費；轉成 `set` 之後能自動去重並做集合比對，但原本的順序和重複次數就不會保留。

### 問題二
測試三中，桌遊與電影去重後都是 `{'amy', 'ben', 'cora'}`（各 3 人），交集與聯集都是這 3 人，兩個差集都是空集合（顯示為 `[]`）。
雖然只有 3 位不同的人，但每人都報了兩場活動，所以報名人次是 `3 + 3 = 6` 人次，總應收則是兩場分開算再相加：`3 × 120 + 3 × 80 = 360 + 240 = 600` 元。
